# Kiểm chứng BTL2

Thư mục này hiện chứa hướng dẫn ca cần kiểm tra, chưa có bộ test tự động đã chạy. Khi hiện thực, mỗi ca ghi mã, UC/quy tắc, setup, thao tác, kết quả mong đợi, kết quả thực tế, người chạy và bằng chứng. Tách dữ liệu kiểm tra lỗi khỏi seed hợp lệ. Không chuyển trạng thái PASS chỉ vì script chạy không báo lỗi.
